# Pool figures

`<figure id>.png` for every figure the Element 3 and Element 8 question pools refer to (Element 9 has none).

They are the original images from the FCC's PDF copies of the same pools, posted on the FCC
[Examinations page](https://www.fcc.gov/wireless/bureau-divisions/mobility-division/commercial-radio-operator-license-program/examinations)
on 6 March 2024 (`Element 3_0.pdf` and `Element 8 Question Pool updated 03062024.pdf`), saved at their
original resolution. Those PDFs have the same questions and answer keys as the 2009 pools in
`content/source/pools/`.

If a figure file is missing, the app still shows the question with a note pointing to the official pool,
and `npm run pools` lists the missing figures.
